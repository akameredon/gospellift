# GospelLift Music Analysis and Promotion Framework

## Level 1: technical file checks
Check file name, type, size and duration where supported. This is not an assessment of musical quality or likely popularity.

## Level 2: human review
Record observations about recording clarity, vocal intelligibility, arrangement, song theme as described by the artist, genre/language, possible short excerpt, intended audience and missing assets/rights. Give practical suggestions with uncertainty noted.

## Level 3: optional AI assistance
Possible future features include lyric transcription, caption drafts, clip timestamp suggestions and review-note summaries. Each requires consent, provider/retention/cost disclosure and human review. Never claim an AI score predicts a hit or spiritual value.

## Campaign measurement
Record platform, link, publish date, reporting window, source and metrics available from the platform. Note unavailable metrics. Separate work completed from observed outcomes.
